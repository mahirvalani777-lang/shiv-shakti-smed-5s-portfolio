# SMED + 5S operations portfolio

A responsive, buildless portfolio case study for Shiv Shakti Printing, based on the supplied `SMED_5S_ShivShakti.xlsx`. Designed for MBA placement recruiters with a concise case narrative, interactive data exploration, 5S practices and an implementation roadmap.

## Run

Open `index.html` directly in a modern browser. No install, build, API keys or external services are required. For a local web preview, serve this folder with any static server.

## Repository structure

- `index.html`: case study and original workbook download
- `assets/style.css`: responsive styling, keyboard focus, reduced-motion and print support
- `assets/app.js`: data-basis switch, activity filter and details, 5S selector
- `assets/data.js`: 18 activity records transcribed from the original detailed sheet, with cell references
- `assets/SMED_5S_ShivShakti.xlsx`: unchanged original workbook
- `assets/favicon.svg`: local vector favicon
- `.github/workflows/pages.yml`: GitHub Pages deployment
- `EVIDENCE.md`: source notes, reconciliation and limitations
